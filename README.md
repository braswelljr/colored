# COLORED 🎨

[![Next.js](https://img.shields.io/badge/Next.js-16-black?logo=next.js)](https://nextjs.org/)
[![TypeScript](https://img.shields.io/badge/TypeScript-5-blue?logo=typescript)](https://www.typescriptlang.org/)
[![Tailwind CSS](https://img.shields.io/badge/Tailwind-4-38bdf8?logo=tailwind-css)](https://tailwindcss.com/)

Experience a world of personalized design with an array of handpicked colors at your disposal.

## ✨ Features

### 🎨 Color Library

- **500+ Curated Colors**: Explore a vast collection of handpicked colors
- **Search Functionality**: Quickly find colors by name or hex code
- **Favorites System**: Save your favorite colors for easy access

### 🎭 Palette Generation

- **Custom Shade Generator**: Create custom Tailwind-style shade scales (50-950) from any base color
- **Curated Palettes**: Browse professionally designed color palettes
- **Interactive Color Picker**: Use the native color picker for precise color selection

### 🔄 Format Conversion

- **Multiple Color Formats**: Convert between HEX, RGB, HSL, HSV, LAB, LCH, and CMYK
- **Real-time Preview**: See converted colors instantly as you type
- **Copy to Clipboard**: One-click copying in your selected format

### 🌙 Dark Mode

- **Theme Support**: Seamless light and dark mode switching
- **System Preference**: Automatically adapts to your system theme

### 📱 Responsive Design

- **Mobile-First**: Optimized for all screen sizes
- **Grid Layout**: Responsive grid that adapts to your viewport
- **Touch-Friendly**: Designed with touch interactions in mind

### ⚡ Performance

- **React Query**: Intelligent caching and data fetching
- **Skeleton Loaders**: Smooth loading states with skeleton screens
- **Next.js 15**: Built with the latest Next.js App Router for optimal performance

## 🚀 Getting Started

### Prerequisites

- **Node.js** 18.x or higher
- **pnpm** package manager

### Installation

#### Clone the repository

```bash
git clone https://github.com/braswelljr/colored.git
```

#### Navigate to the directory

```bash
cd colored
```

#### Install dependencies

```bash
pnpm install
```

#### Start the development server

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
